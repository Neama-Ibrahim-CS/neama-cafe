# Neama Café — Specialty Coffee & Artisan Bakery

A responsive and modern front-end web application for an artisanal coffee shop and bakery. Built completely with semantic HTML5, modern custom CSS3, and Vanilla JavaScript with local state management.

---

## Key Features

- Dynamic Menu Spotlight: Category popups dynamically rendering specialty beverages and bakery items from a local JavaScript dataset.
- Real-time Bag & Cart Hub: Interactive bag counter, item quantity controls, subtotal and 5% service calculation, and dynamic receipt generation.
- Interactive Wishlist: Save favorite items with animated heart particle bursts and quick-navigation straight to the menu section.
- Multi-option Checkout Flow: Interactive modal supporting dine-in table reservations (with date/time/guest pickers), takeaway, and delivery options.
- Client-side Form Validation: Smart regex-based validation for Egyptian phone numbers (010, 011, 012, 015) and structured contact inputs.
- Micro-interactions & Motion: Hero typing effect, interactive hover states, expandable bento gallery, and floating toast alerts.
- Cross-Device Responsiveness: Adaptive layout designed for mobile, tablet, and desktop viewports.

---

## Technologies Used

- HTML5: Semantic markup structure
- CSS3: Custom properties, flexbox, CSS grid, glassmorphism, and keyframe animations
- JavaScript (ES6+): Pure Vanilla JS for DOM manipulation and application state (no frameworks)
- Icons: Font Awesome 6
- Fonts: Google Fonts (Playfair Display & Poppins)
